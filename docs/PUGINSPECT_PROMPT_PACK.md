**Key facts:**
- Backend: Node 24, Express 5, Apollo Server, Drizzle ORM, TypeScript ESM (`"type": "module"`)
- Build: `pnpm --filter backend build` (tsc → `dist/`). Dev: `pnpm --filter backend dev` (build + run)
- Frontend: React 19, Vite, TanStack Router (file-based routing), Mantine UI
- Route tree is auto-generated by the TanStack Router Vite plugin — run dev once after adding a new route file to regenerate `routeTree.gen.ts`
- `characterRioSnapshots.rawData` is JSONB typed as `RaiderIoCharacterApiResponse`. Key paths for card: `mythic_plus_best_runs[0].mythic_level` (top key), `mythic_plus_scores_by_season[0].segments.all.{score,color}` (M+ score + color), `raid_progression` (record of slugs → progression), `thumbnail_url` (avatar)
- Nginx bot detection: `$is_bot` map routes bots for `/{region}/{realm}/{name}` to `/meta/` on the backend. The `/card/` endpoint must also be proxied through Nginx.
- `config.publicOrigin` = `https://puginspect.com` (or `PUBLIC_ORIGIN` env var)
- `getCharacterMetaSnapshot()` in `persistence.ts` is the existing lightweight snapshot query for SEO — deliberately ignores `expiresAt` (stale data OK for bots). The card endpoint should follow the same pattern.

---

## Locked Decisions

- **No verdict/readiness algorithm.** Cards show raw signals only. Users decide.
- **Card dimensions:** 1200 × 630 px (standard og:image).
- **Card renderer:** `@vercel/satori` (JSX → SVG) + `@resvg/resvg-js` (SVG → PNG). No native deps.
- **Card caching:** in-memory TTL map in `characterCard.ts` (15-minute TTL, same as RIO cache). Not persisted to Postgres — simplicity over durability.
- **Compare route:** max 4 characters, URL param `?chars=region/realm/name,region/realm/name,...`
- **Header stat slots (P2):** ilvl, RIO score, top key (existing) + raid progression summary + last active (new). Best WCL parse is shown only when `raidLogsData` is already loaded (no eager fetch for header only).

Add a new exported function after `getCharacterMetaSnapshot()`. It returns everything needed to render the card:

```ts
export type CharacterCardSnapshot = {
  name: string;
  realm: string;
  class: string | null;
  specialization: string | null;
  race: string | null;
  thumbnailUrl: string | null;
  itemLevel: number | null;

export async function getCharacterCardSnapshot(

```

The query joins `characters` with `characterRioSnapshots` (LEFT JOIN, same as `getCharacterMetaSnapshot`), selecting:
- `characters`: name, realm, class, specialization, race, thumbnailUrl
- `characterRioSnapshots.mythicPlusScore`

Like `getCharacterMetaSnapshot`, this deliberately ignores `expiresAt` — stale data is fine for card renders, and card requests must never trigger upstream API fetches.

Return `null` (not throw) on DB errors, consistent with the existing pattern.

### 3. `apps/backend/src/seo/characterCard.ts` — new file

Create this file. It exports one function:

```ts
export async function renderCharacterCard(
  region: string,
  realm: string,
  name: string
): Promise<Buffer | null>
```

**Structure:**

**Font loading (module-level, lazy singleton):** Fetch Inter Regular from jsDelivr on first call and cache as `ArrayBuffer`:
```
https://cdn.jsdelivr.net/npm/@fontsource/inter@5.1.1/files/inter-latin-400-normal.woff
```
If the fetch fails, log the error and return `null` from `renderCharacterCard` — no font = no card.

**In-memory cache:** A `Map<string, { png: Buffer; expiresAt: number }>` with 15-minute TTL (900_000 ms). Cache key: `${region}:${realm}:${name}`. Check cache first; skip render and return cached PNG if still valid.

**Card render:**
1. Call `getCharacterCardSnapshot({ region, realm, name })` from `../db/persistence.js`
2. If snapshot is null, return null (endpoint will 404)
3. Determine class color using the same mapping as the frontend (`CLASS_COLORS` in `util/util.ts` — replicate the map or import a shared utility if one exists). Fall back to `#7a8290` if class is unknown.
4. Derive a short raid progression string for the current tier: find the entry in `snapshot.raidProgression` whose key matches `"tier-mn-1"` (the current `DEFAULT_RAID`). Format as e.g. `"4/8 M · 8/8 H"` if mythic > 0, else `"8/8 H"` if heroic = total, else `"N/A"`. If raidProgression is null or the key is missing, show `"—"`.
5. Build the Satori JSX template (1200 × 630). Design:
   - Dark background: `#16181d`
   - 4px accent bar at top using the class color
   - Left section (~280px wide): avatar image from `snapshot.thumbnailUrl` (60×60, circular clip, class-color ring border). Below it: character name (class color, bold, ~22px), `<guild> (EU) Realm` or `(EU) Realm` if no guild (we don't have guild in the snapshot — just show realm + region), race + spec + class (grey, ~13px)
   - Right section: a 2×3 stats grid (label + value pairs):
     - Item Level | M+ Score | Top Key
     - Raid Prog  | Last Active (we don't have this in the card snapshot — leave this slot as blank or fill with region)
   - Bottom-right: `puginspect.com` in small grey text
   - M+ score colored with `snapshot.mythicPlusColor ?? '#7a8290'`
   - Top key formatted as `+{n}` or `—`
6. Call `satori(jsx, { width: 1200, height: 630, fonts: [{ name: 'Inter', data: fontBuffer, weight: 400 }] })` → SVG string
7. Convert to PNG: `new Resvg(svg, { fitTo: { mode: 'width', value: 1200 } }).render().asPng()`
8. Store in cache and return the Buffer

Import Satori as:
```ts
import satori from '@vercel/satori'
import { Resvg } from '@resvg/resvg-js'
```

Satori takes a React-element-like object — use `React.createElement` or the JSX transform. Since this is a Node ESM module, use `React.createElement` calls directly to avoid needing a JSX config change, or add `"jsx": "react"` to the backend `tsconfig.json` and import React. **Check the existing `tsconfig.json` first and match what's already there.**

```ts
// Last active: most recent run timestamp across recent + best runs
function getLastActiveDays(raiderIo: RaiderIo | null | undefined): number | null {
  const runs = [
    ...(raiderIo?.recentMythicPlusRuns ?? []),
    ...(raiderIo?.bestMythicPlusRuns ?? []),
  ];
  if (!runs.length) return null;
  const latest = Math.max(...runs.map(r => new Date(r.completed_at).getTime()));
  if (!isFinite(latest)) return null;
  return Math.floor((Date.now() - latest) / (1000 * 60 * 60 * 24));
}

// Raid progression summary for DEFAULT_RAID ("tier-mn-1")
function getRaidProgressSummary(raiderIo: RaiderIo | null | undefined): string | null {
  const prog = raiderIo?.raidProgression;
  if (!prog?.length) return null;
  const current = prog.find(p => p.raid === "tier-mn-1");
  if (!current) return null;
  const total = current.total_bosses;
  const mythic = current.mythic_bosses_killed ?? 0;
  const heroic = current.heroic_bosses_killed ?? 0;
  if (mythic > 0) return `${mythic}/${total} M`;
  if (heroic > 0) return `${heroic}/${total} H`;
  const normal = current.normal_bosses_killed ?? 0;
  if (normal > 0) return `${normal}/${total} N`;
  return "—";
}
```
